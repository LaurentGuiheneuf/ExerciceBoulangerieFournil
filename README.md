Ceci est l'exercice proposé par Christian L ( Studi.com ) pour ma formation GDWWM&IA Octobre 2026.
Il fallait créer une Page Web pour une Boulangerie.
Créez le dossier fournil/ et le fichier index.html avec le squelette HTML5 complet (titre : « Le Fournil — Boulangerie artisanale »).
Dans le body, créez un header contenant un h1 (nom de la boulangerie) et un nav avec trois liens factices : Accueil, La carte, Contact (href="#" pour l'instant).
Dans main, créez deux section : « Notre savoir-faire » (h2 + un paragraphe de 2 phrases) et « Nos produits phares » (h2 + trois article, chacun avec un h3 et une phrase).
Créez un footer avec l'adresse fictive et les horaires.
Ajoutez des commentaires HTML pour repérer chaque zone.
Ouvrez la page avec Live Server, puis inspectez-la (F12) : repérez le body et dépliez l'arbre.
Validez le code sur validator.w3.org (onglet « Validate by direct input »).
